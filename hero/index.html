What this hero is, and is not

This is a procedural 3D concept built from the written brief. The reference panorama named in the build directive did not arrive with it, so the composition follows the directive's description; rear views and unseen surroundings are artistic extensions, not recovered details. Nothing here is a live device session, a measured task count, or an execution receipt. The task sequence is illustrative: a dot travels from the hub to a device, the device acknowledges, and a receipt indicator appears. No command leaves this page.

What HERMES TV is

What: HERMES TV is a local-first smart TV agent interface for Android TV and Google TV. It connects a television to a Hermes agent runtime that the user owns and controls.

Who it is for: People who run their own Hermes agent host and want a television control surface for it.

What it does: It is being built to provide remote navigation, conversation, and optional voice control from the TV. Agents execute on the user-controlled host, not inside this website.

Status (as of 2026-10-20): In development. No APK is published. Machine-readable fact sheet: facts.json.
